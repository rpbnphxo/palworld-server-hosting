## 面板服、游戏云 VPS、RCS 差在哪

**面板服**面向完全不想碰命令行的人。下单后进面板，游戏类型选“幻兽帕鲁”，点“开启实例”，几十秒就起好了，对外地址和端口直接显示在面板上，复制发给朋友即可。面板里还能重装或切换游戏，同一台机器可以换成其他近 20 款游戏，玩腻了不用重新买。

**游戏云 VPS** 给你一台完整机器，系统可选 Windows 2019 或 Ubuntu。Windows 用远程桌面连进去，PowerShell 跑一条一键脚本；Linux 用 SSH 连上跑 wget 管道命令，装完服务会自动开机自启，服务器重启后帕鲁进程不会消失。自由度换来的是你得自己管端口映射和配置文件。

**云服务器 RCS** 是规格更高的一档，Xeon Platinum 和 AMD EPYC 7702，从 4 核 8G 到 8 核 16G。二十人往上的服，或者你打算同时跑点别的东西，才需要考虑它。

判断规则很简单：不懂 Linux、只想开帕鲁 → 面板服；要装 MOD、改参数、顺便跑别的服务 → VPS；20 人以上 → RCS。

## 开服流程：面板服三步，VPS 两条命令

面板服是最短的路径。下单选好机型和计费方式，进控制台点开实例，等几十秒，把面板右侧的对外地址和端口抄下来。客户端这边，Steam 启动游戏，主菜单选“加入多人游戏（专用服务器）”，底部输入框填 `服务器地址:8211`，有密码就再输密码，点连接。

VPS 走脚本。Windows 系统在 PowerShell 里执行安装脚本，看到部署成功的提示就完成了，整个过程二十分钟以内。装完之后还有一步不能忘：在控制台做 NAT 端口映射，新建规则，把内网的 8211 端口映射出去。幻兽帕鲁用的是 UDP 8211，映射没做，朋友那边就会一直卡在连接中。

改世界参数有个坑，Linux 和 Windows 都一样：`PalWorldSettings.ini` 初始是空的，得先把 `DefaultPalWorldSettings.ini` 里的内容整段复制进去再改，直接编辑默认模板不会生效。Linux 下路径是 `/home/ubuntu/Steam/steamapps/common/PalServer/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`。常改的几项是 `ServerName`、`ServerPassword`、`AdminPassword`、`ServerPlayerMaxNum`、`ExpRate`、`PalCaptureRate`、`DeathPenalty`，改完重启实例生效。

## 五个容易踩的坑

**内存泄漏。** 幻兽帕鲁跑久了内存会一路涨，最后卡顿甚至崩服，这是游戏本身的问题，不是服务器的问题。两个应对办法：8G 内存的机器额外开 8–12G 的 SWAP 兜底；或者配自动重启脚本，内存占用超过 90% 自动重启帕鲁进程，回档大概 10 秒，玩家基本感觉不到。

**端口没映射。** 朋友连不上，九成是这里。控制台 → NAT 端口映射 → 新建规则，内网 8211 映射出去，把映射后的公网地址和端口发人。

**配置文件改错地方。** 前面说过，`PalWorldSettings.ini` 是空的，必须从默认模板复制内容进去，改模板文件本身无效。

**主机平台连不上。** PS5 和 Xbox 不能通过 IP 直连，只能从公共服务器列表加入，也不支持 Tailscale 组网。想做成半私密，只能设服务器密码。这条很多教程不写，主机玩家买了服务器才发现进不去。

**低价档撑不住推荐人数。** 官方文档给的服务器要求是最低 4 核 8G、推荐 4 核 16G、多人 32G 以上。三十元档的面板服达不到这个配置，只适合 2–4 人短时段联机；玩家反馈里，4 核 8G 开 5 人以内基本够用，跑久了有内存压力，4 核 16G 才撑得住 10 人左右。别拿入门档去开十人服，卡的是你自己。
